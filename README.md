# envybash
An attempt of reimplementing EnvyControl in a shell script

**This project will no longer try to be a direct replica of EnvyControl and serves its purpose as a quick wrapper script for turning the dGPU off. This is mainly for NVIDIA gpus that don't have RTD3 power management functionality. If you have a modern NVIDIA gpu, you're better off using EnvyControl. I am not responsible for any system issues when you run this.**
