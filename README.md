# envybash
An attempt of reimplementing EnvyControl in a shell script

**This project will no longer try to be a direct replica of EnvyControl and instead will just be a quick wrapper script for turning off NVIDIA gpus that don't have the modern RTD3 power management functionality. It will not account for your existing configurations nor will it detect if you have an NVIDIA-specific setup. You are on your own if your system breaks. Run at your own risk.**
