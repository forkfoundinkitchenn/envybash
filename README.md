# envybash
NVIDIA power management wrapper script written in Bash

at the moment, this project is in a prototype phase and is not meant to be a drop-in replacement for envycontrol nor similar tools

**use at your own risk**!

install:
```
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/forkfoundinkitchenn/envybash/refs/heads/main/install.sh)"
```
usage:
```
flags: -i (integrated), -h (hybrid), -q (query)
```

should work on:
- Fedora
- Void Linux

Derivatives of these distros currently do not work.
